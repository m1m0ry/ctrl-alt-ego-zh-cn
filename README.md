# Ctrl Alt Ego 简体中文

非官方简体中文补丁。

适用游戏版本：Steam v1.5.8（build 22614084，Windows/Proton）。

[下载覆盖包](https://github.com/m1m0ry/ctrl-alt-ego-zh-cn/releases/latest)

## 安装

退出游戏，将覆盖包解压到游戏安装目录，覆盖同名文件。需要时在游戏“设置 → 语言”选择“简体中文”。

## 恢复

切回 English 并退出，移走新增的 zh-cn 目录，再用 Steam 验证恢复原文件。
